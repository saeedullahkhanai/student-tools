Contact Student Tools

Have a suggestion, found a calculator issue or want to request a new student tool? We welcome useful feedback that can help improve the website.

Report a Calculator or Website Issue

If you notice an incorrect result, broken link, display problem or another issue, please provide as much useful information as possible. Include the name of the tool and, if relevant, the values you entered so the issue can be checked more easily.

Suggest a New Tool

You can also suggest a calculator or study utility that would be useful for students. Examples include academic calculators, productivity tools and other simple utilities.

Contact Method

This website is currently a static GitHub Pages site and does not use a built-in contact form or backend messaging system.

A public contact email can be added here when a dedicated email address for Student Tools is available.

Before Sending Feedback

  • Include the name of the tool you are referring to.
  • Explain the issue or suggestion clearly.
  • For calculation issues, include an example input and expected result.
  • Do not send passwords, financial information or other sensitive information.

Explore the Website

You can also browse the All Student Tools or read the available student guides.

For information about the website and its purpose, visit About Student Tools.
